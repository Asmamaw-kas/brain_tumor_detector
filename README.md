# 🧠 Brain Tumor Detection Web App

A full-stack web application for detecting brain tumors from MRI images using Deep Learning. Built with FastAPI (backend) and React (frontend).


## ✨ Features

- 🖼️ **Image Upload**: Drag & drop or click to upload MRI scans
- 🔍 **AI-Powered Detection**: Predicts tumor presence with confidence scores
- 📊 **Visual Results**: Color-coded results with confidence bar visualization
- 💡 **Detailed Reasoning**: Explains prediction with confidence levels
- 📱 **Responsive Design**: Works on desktop and mobile devices
- ⚡ **Real-time Processing**: Fast predictions using TensorFlow model

## 🏗️ Tech Stack

### Backend
- **FastAPI**: High-performance API framework
- **TensorFlow**: Deep learning model inference
- **Pillow**: Image processing
- **NumPy**: Numerical operations

### Frontend
- **React**: UI library
- **Vite**: Build tool
- **Axios**: HTTP client
- **CSS3**: Styling with gradients and animations
